Grocery Theme Common
===============
The Grocery Theme Common module enhances the grocery store experience by adding customizable features such as Nutritional Facts, Product Brand, Label, and Highlight, Hover Images, Progressive Web Application (PWA) support, and more. It also offers settings for a Right-Side Cart, Lazy Load, and customization options like Login Banner Image and Transparent Header Logo to improve both functionality and design.
